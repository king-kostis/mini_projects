###  Simple Console Based Mood Tracker Application
#### Project Description:
This application allows users to enter a particular mood they are feeling on a particular day. They can also include notes to the mood they are feeling.

#### Functional Features: 
* Add mood
* Delete mood by name, date and time
* Delete mood(s) by date
* Edit mood notes
* Search mood(s) by date 
* Search mood by name, date and time

<br>

### Simple Console Directory Explorer Application
#### Project Description:
This application basically lets a user manage files or directories by performing operations on them.

#### Functional Features:
* Create a file
* Rename a file
* Delete a file
* Create a directory
* Rename a directory 
* Delete a directory
* Printout files in a directory

<br>

### Simple  Console Based Grocery Shopping Application
#### Project Description:
This application tracks and calculates the price of a users grocery list

#### Functional Features:
* Add grocery items to the list
* Checks if a grocery item is on the list
* Calculates the price of all groceries

<br>

### Console Based Pet Scheduler Application
#### Project Description:
This application is a pet management system that keeps track of pets and their appointments with the vet

#### Functional Features:
* Register a pet
* Schedule an appointment for your pet
* Serialize/Deserialize pet and appointment objects to or from a .ser file for persistence
* Display details such as;
  * all registered pets
  * all appointments for a specific pet
  * upcoming appointments for all pets
  * past appointments for all pets
* Generate reports on ;
  * upcoming appointments
  * overdue appointments
